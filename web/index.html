Measured on the selected index with k from the sliders above, at any sparsity: protein reads, pairs of 50 aa, with no translation or errors. Each k-mer a read shares with a group is kept at 1 in m, so hits are binomial, which averages over hash functions; one index is one draw, shown as a range where measured. The floor uses kfp's evidence with one size of key. These indexes are one representative per MGnify90 unit and denser than the release, so values do not carry over to it. At k 5 and 6, relatives' identities are mostly unknown and count as wrong, so "or a relative" reads low. The bit floor is not yet calibrated to kfp's scores, whose bits vary by key. Per-target values take even abundance and were tested only at depth 6, where recall per target is up to 0.14 too high at 1 in 32; expect worse at greater depth, as reads of one target share k-mers. Chance is small here but grows with the index. Assignment to the best group is not modelled here.

Model: k-mer anchors on group representatives, with conserved and variable blocks fitted to kfp's 90%-AAI table (recall ceiling 0.96), and a conservation rate shared by each read fitted to the simulation. Index size assumes 225 residues per representative and 6 bytes per posting; the representative share is held fixed as the database grows, which is a stand-in until the scale profile is measured. Chance assumes 3 frames per read, with a measured correction at protein k 5–9 and composition alone (a lower bound) elsewhere. Reduced alphabets raise identity by the share of substitutions staying within a class (from BLOSUM62, scaled 1.6× to fit simulated reads on three alphabets), and lower chance by class frequencies. Nucleotide mode reads identity as nucleotide identity, assumes 3 letters per residue and uniform bases, and uses conservation fitted on protein with no codon structure, so treat it as a rough guide.

Analyse a protein set

Runs in this browser; files are not uploaded. Sets over 20 M residues are sampled at random to stay within wasm's memory. "Independent" is what independent residues with this set's composition would give. Decoys are one random half's sequences reversed, matched to the other half. Between halves counts matches between sequences of the two halves, so with homologues it is far above chance. Above k 7 in a set this small, a few k-mers dominate the decoy rate.
